# Naija Bowl Kitchen — Project Description

Naija Bowl Kitchen is a responsive, three-page student demonstration website celebrating traditional Nigerian soups. Visitors can explore dishes from different culinary regions, compare options, save favorites, and complete a sample order form.

## Homepage
Introduces the food concept, highlights Nigerian cuisine, and provides navigation to the menu and order pages.

## Menu
Loads 15 dishes asynchronously from a local JSON file using the Fetch API and error handling. Each card shows a food image, dish name, region, price, spice level, estimated preparation time, category, and detailed description. Visitors can filter categories, save favorites using localStorage, and open a modal dialog.

## Order
Visitors can choose a soup, enter their contact information and quantity, and see a calculated total. The separate confirmation page displays submitted form data. This is a demonstration only: no actual order or payment is processed.

## Technologies
Semantic HTML, responsive CSS Grid and Flexbox, vanilla JavaScript ES Modules, JSON, Fetch API, localStorage, and native HTML dialogs. No third-party CSS frameworks.

## Before submission
Verify photo licenses and credits. Egusi Soup and Catfish Pepper Soup use substitute photos, not verified exact dish photos. Add your public demonstration video link to each footer, test with Live Server, run the course audit, and check mobile Lighthouse scores.
